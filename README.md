# PRE Buyer Portal — The Brooks

A responsive, mobile-first demonstration of the proposed PRE Group home-buyer portal, designed in the approved **light theme**.

## Features

- **Home:** property overview, next illustrative installment, construction stage and expected handover.
- **Installments:** illustrative financial summary and payment schedule.
- **Construction Progress:** October 2026 construction milestones and building-specific delivery estimates.
- **Documents:** document categories and demo document listings.
- **Profile & Support:** official PRE Group hotline and email contacts plus an on-device demo inquiry form.

## Running

Open `index.html` in a browser. The committed site is a standalone, dependency-free HTML file and requires no build process.

## GitHub Pages

In the GitHub repository, choose **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)**, and save.

## Important demo limitations

- All buyer details, payments, due dates, percentages and payment statuses are **illustrative**, not real records.
- Building stages and expected delivery quarters were derived from the October 2026 PRE Group progress report.
- The October report did not provide numerical completion percentages. The 72% example is illustrative.
- Photos and the original 22-page construction PDF are **not included in this GitHub commit**. They remain in the original full web app ZIP package supplied in the ChatGPT conversation. Add them from that package before presenting the site as a complete reconstruction.
- The support form does not send or save inquiries; authentication and a secure backend will be needed for a production release.
- Never upload real buyer identities, contracts, payment records or secrets to a public repository.

This is a **GitHub-compatible compact frontend** of the PRE Buyer Portal rather than an exact copy of the original multi-file ZIP.
